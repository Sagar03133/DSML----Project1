# Smart Pricing Insights for Real Estate


### Goal: 
Help real estate stakeholders optimize pricing strategies by identifying key factors influencing property prices and offering data-backed insights to support valuation decisions.

### Key Insights and Solutions

- Analyzed features such as square footage, number of bedrooms, location, furnishing status, and number of bathrooms.
- Detected outliers and cleaned inconsistent data to ensure accuracy in analysis.
- Visualized correlations between variables like area vs. price and location vs. average price.
- Identified top contributing factors affecting house prices through visual EDA.
- Flagged anomalies in pricing to help detect overvalued or undervalued listings.

### Business Impact
- Enabled real estate professionals to make informed pricing decisions based on market data
- Improved pricing accuracy and competitive positioning of listings
- Reduced time and guesswork involved in pricing properties manually

Skills Used - Python (Pandas, Matplotlib, Seaborn, Skicit-learn), Tableau, Exploratory Data Analysis (EDA), Machine Learning, Feature Engineering, Model Evaluation
